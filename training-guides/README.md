# Training guides

Choose the guide that matches the project's goal:

- [Tumor present or absent](TUMOR_PRESENCE_CLASSIFIER.md): one yes/no prediction for a whole PET/CT scan.
- [Lesion segmentation](../FINE_TUNING_GUIDE.md): a 3D mask that marks lesion voxels.

These are different tasks and produce different outputs. The classification guide is a starting plan; it does not add a trained classifier to `classifier.ipynb`.
